# Draculonforge Website

## Folders
- index.html: homepage
- css/style.css: site appearance
- js/main.js: future interactive features
- pages/: additional pages
- images/: artwork and textures
- downloads/: public downloads

## Update steps
1. Edit and save.
2. Commit in GitHub Desktop.
3. Push origin.
4. Refresh draculonforge.com with Ctrl+F5.
